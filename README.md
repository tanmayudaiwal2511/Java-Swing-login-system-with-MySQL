# Java Swing Login System with MySQL

Modern login system built with Java Swing, MySQL, BCrypt password hashing,
user roles and an admin panel.

## Features
- Register and login with hashed passwords
- Custom title bar with minimize and close buttons
- Dashboard with sidebar and stat cards
- Admin panel to view and delete users
- Change password page

## Setup
1. Create the `auth_db` database and `users` table in MySQL.
2. Copy `src/main/resources/db.properties.example` to `db.properties` and enter your MySQL password.
3. Run `Main.java`.
